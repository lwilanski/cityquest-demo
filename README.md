# CityQuest – web demo

Live demo: https://lwilanski.github.io/cityquest-demo/

CityQuest is a mobile city-exploration game built with Flutter. When you walk into a geofence around a landmark, the app checks you in automatically, shows the story of the place and awards XP. It also has quests, badges and a friends leaderboard.

This repository holds only the compiled web build used for presentations. Everything runs on demo data for Kraków, and a simulated walker stands in for real GPS.

Tip: open the demo in Chrome, press F12, then Ctrl+Shift+M to view it at phone size.
